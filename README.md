# Смена

Мобильное приложение для оператора экскаватора-погрузчика. Помогает записывать
заказы, клиентов, адреса работ, расходы и заработок.

## Возможности

- заказы с датой, видом работ, часами, стоимостью, доставкой и статусом;
- календарь загрузки и быстрый переход к сегодняшнему дню;
- клиенты с поиском, телефоном, заметками и историей суммы заказов;
- учёт топлива, обслуживания, запчастей и других расходов;
- раздельный расчёт выполненных, оплаченных и запланированных заказов;
- маршрут к месту работы через Яндекс.Карты или Яндекс.Навигатор;
- полноценная работа офлайн в браузере и Android-приложении;
- автоматические локальные резервные копии (до пяти последних), включая медиа;
- фото и голосовые заметки к заказам;
- отчёты в CSV для Excel и печать в PDF;
- экспорт событий в календарь (`.ics`) и клиентов в контакты (`.vcf`);
- резервная копия всех данных в JSON из раздела «Настройки»;
- двустороннее объединение данных между телефоном и компьютером через пакет синхронизации.

Данные по умолчанию хранятся на устройстве. Регулярно скачивайте резервную копию,
особенно перед сменой телефона или очисткой данных приложения.

**Опубликованная версия:** https://digger-log-app.lovable.app

## Разработка

Нужен Node.js 20+.

```sh
npm install
npm run dev
```

Проверки перед публикацией:

```sh
npm run lint
npm run test
npm run build
```

Для локального офлайн-бандла Android-приложения:

```sh
npm run build:capacitor
npx cap sync android
```

После сборки APK данные, фотографии и голосовые заметки работают без сети.

## Синхронизация

В разделе «Настройки» нажмите «Выгрузить пакет» на одном устройстве, передайте JSON
на другое и нажмите «Объединить пакет». Для двустороннего обмена выгрузите объединённые
данные обратно. Конфликты разрешаются по времени последнего изменения, текущие записи
не удаляются.

## Android

Инструкция по сборке APK находится в [ANDROID.md](./ANDROID.md). После обновления
кода используйте `npm run android:sync`, чтобы синхронизировать Capacitor и проверить
разрешения геолокации.
